# React Text Tokenizer

A React application that allows the user to enter text and tokenize it into individual words and punctuation marks.

## How It Works

The application:

- Accepts text input from the user
- Separates words and punctuation into tokens
- Ignores spaces
- Displays the resulting tokens in a comma-separated list

## Technologies

- React
- JavaScript
- HTML
- CSS
